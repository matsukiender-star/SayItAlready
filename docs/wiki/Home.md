¡Dilo Ya! es un juego de fiesta para adivinar palabras con el teléfono en la frente. Tus amigos te dan pistas y tú inclinas el teléfono: **hacia abajo si adivinaste, hacia arriba para pasar**.

Esta wiki reúne toda la documentación del proyecto, para quienes juegan y para quienes quieren cambiar el código.
